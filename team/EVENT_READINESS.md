# EVENT READINESS — pre-tournament checklist (CEO owns; drive to green before every DGPT event)

The owner's rule: BEFORE an event, everything must be verified ready — especially the registered field and the
background event wiring, which have broken before. File every gap as a HIGH-PRIORITY board task.

## ACTIVE EVENT: Ledgestone Open — starts ~2026-07-30 (~4 days out). GET IT READY. Job #1.

### A. The Picks / Draft (truth-of-data — the top risk)
- [ ] The event exists in the app with the CORRECT event ID / number / name, matching the real DGPT/PDGA
      Ledgestone Open. (Past bugs came from mismatched event IDs/naming in the background — verify explicitly.)
- [ ] The pickable PRO FIELD = the REAL registered field for THIS event. Cross-check the app's list against the
      live PDGA/DGPT Ledgestone field page. No stale, missing, or extra players.
- [ ] Picks UNLOCK as soon as the field is in (members can draft). Draft/snake order correct. Pick lock at first
      tee configured. A player who WDs is handled per the rules, not left as a broken pick.

### B. Standings / Stats / Schedule / History
- [ ] Season standings render correctly and are ready to update from this event's results.
- [ ] Stats pages correct. Schedule shows the Ledgestone Open with the right dates. History reflects prior events correctly.

### C. Live Chains (queued, not live yet)
- [ ] Live Chains is wired to THIS event's ID and ready to start updating the moment the event goes live —
      nothing to display now (not live), but confirm the plumbing/event binding so it "just works" at tee-off.

### D. Background data wiring (the recurring pain point)
- [ ] Event numbers, IDs, naming, and result-source identifiers all line up end-to-end (app <-> data source).
      Trace one pick through to how it will score, and confirm the identifiers match. Fix any mismatch NOW.

## REUSABLE (for future events): repeat A-D for each upcoming DGPT event ~5 days before it starts. Log the
## event, what was checked, what was fixed, and confirm green in team/logs/ceo.md and the daily report.
